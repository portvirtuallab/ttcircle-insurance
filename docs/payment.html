How this stage works

Three checks before the cover is live.

  • 1 · Payment code
    Verified against the TTCircle ledger. A code can only be used once.
  • 2 · Quote code
    Retrieves the policy you priced in stage two.
  • 3 · Confirmation
    You check the details on screen, then the certificate is generated and emailed.
  • Not found — check for typing errors; codes are case sensitive.
  • Already used — a payment code activates one policy only. Request a new one.
  • System unavailable — the backend did not answer. Wait a moment and send the code again.
The certificate is your proof of cover. Keep the PDF: the claims stage asks for it.
